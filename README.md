## Реализовано

- SQLite-таблица `recipes(id, name, difficulty, cooking_time_min)`.
- Полный CRUD через REST-подобный API.
- Фильтрация `GET /api/recipes?difficulty=hard`.
- Сортировка по времени приготовления по возрастанию.
- Проверка уровней `easy`, `medium`, `hard` и положительного целого времени.
- Ответы `400` для некорректных данных и `404` для отсутствующего рецепта.
- Адаптивный интерфейс с фильтром и модальным окном добавления/редактирования.
- Автоматические API-тесты.

## API

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/api/recipes` | Список рецептов |
| `GET` | `/api/recipes?difficulty=hard` | Фильтр по сложности |
| `GET` | `/api/recipes/:id` | Один рецепт |
| `POST` | `/api/recipes` | Создать рецепт |
| `PUT` | `/api/recipes/:id` | Обновить рецепт |
| `DELETE` | `/api/recipes/:id` | Удалить рецепт |

Тело для `POST`/`PUT`:

```json
{
  "name": "Паста с томатами",
  "difficulty": "easy",
  "cooking_time_min": 25
}
```

## Запуск

Требуется Node.js 22.5 или новее (используется встроенный модуль `node:sqlite`).

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. База создаётся автоматически в `data/recipes.db`.

## Публичная ссылка

**Активной публичной ссылки сейчас нет.** Старая ссылка больше не подключена к запущенному туннелю и показывает Cloudflare Error 1033. Quick Tunnel не имеет постоянного адреса: новый URL появится в выводе `cloudflared` только после успешного подключения к Cloudflare.

### Запуск Cloudflare Tunnel

Установите `cloudflared`, затем из папки проекта выполните:

```powershell
npm run tunnel
```

Либо в Git Bash:

```bash
bash scripts/start-cloudflare-tunnel.sh
```

Приложение будет запущено на порту `3007`. Новый публичный адрес появится в выводе `cloudflared`; он действует, пока запущены приложение и туннель, и меняется при следующем запуске.
